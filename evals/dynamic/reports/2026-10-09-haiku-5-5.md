## The CLI doesn't know Haiku 5.5 yet

Claude Code v2.1.286 logs `unrecognized_model` for `claude-haiku-5-5` and the API serves it, but the
CLI prices it at a rate other than Haiku 5.5's: these runs report about $4.26 API-equivalent in all,
more than the Haiku 4.5 runs, for a model priced lower. The session budget cap is checked against the
same estimate, which is why `agent-spec-model` stopped at $0.75. Update Claude Code before reading the
costs or tightening the caps. The suites' default `haiku` alias resolves per CLI version; pass
`--models claude-haiku-5-5` to be sure which Haiku runs.

## What Haiku doesn't stand in for

These suites test plumbing — that hooks fire and their messages arrive, and that a read rule and a
path reach the plugin's files — where the cheapest model is enough. They don't test judgment, and
they don't test how Opus 5.5 or Sonnet 5.5 return text written just before a tool call, which can come
back as a progress-update thinking block. The `triage` and `debug` suites stay on `sonnet` and `opus`.
